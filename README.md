# t-bot-lokal

Einfacher Paper-Trading-Bot für Spot- und Futures-Märkte (Long und Short,
Hebel je Börse konfigurierbar). Die vollständige Dokumentation liegt in
[`docs/`](docs/README.md): Handbuch ([`docs/MANUAL.md`](docs/MANUAL.md)),
Backtesting ([`docs/backtesting.md`](docs/backtesting.md)) und Änderungen
([`docs/CHANGELOG.md`](docs/CHANGELOG.md)).
